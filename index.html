DATA & METHODOLOGY

About this project

This Victorian case study uses the Local Government Performance Reporting Framework, Victorian waste statistics, recreation facility records, and local parks datasets. Comparisons are limited to councils and years with reported observations. Some charts use selected councils or a single council's parks records, as labelled.

Interpretation: community consultation satisfaction is a perception measure, not a direct survey of changing service priorities. Financial position is not the same as spending on services. Map 1 uses LGA polygons where available; map 2 uses individual facility locations; map 3 uses H3 hexagonal bins. Map tiles require an internet connection.

Interactive charts use Vega-Lite. Run this project through VS Code Live Server with an internet connection for the Vega libraries; keep the data folder alongside these files.
